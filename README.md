# 📊 CodeAlpha Financial Health Dashboard

## 📌 Project Overview

This project is an interactive **Financial Health Dashboard** developed using **Microsoft Power BI** as part of my **CodeAlpha Power BI Internship – Task 1**.

The dashboard provides a comprehensive view of an organization's financial performance through key financial metrics, financial statements, profitability analysis, cash flow analysis, and revenue forecasting.

---

## 🎯 Objective

The main objective of this project is to analyze an organization's financial health and provide meaningful insights to support financial planning and decision-making.

The dashboard focuses on:

- Financial performance analysis
- Profitability analysis
- Income Statement analysis
- Balance Sheet analysis
- Cash Flow analysis
- Profitability trends over time
- Revenue forecasting
- Interactive financial insights

---

## 📊 Dashboard Features

### 💰 Financial KPIs

The dashboard provides important financial KPIs including:

- Revenue
- Gross Profit
- Operating Profit
- Net Profit
- Net Profit Margin

These KPIs provide a quick overview of the organization's financial performance.

---

### 📈 Revenue & Profitability Analysis

The dashboard includes visualizations for:

- Revenue
- Cost of Sales
- Gross Profit
- Operating Profit
- Net Profit
- Net Profit Margin

A profitability trend analysis is included to understand how financial performance changes over time.

---

### 🔮 Revenue Forecasting

A **6-month revenue forecast** is included using Power BI's forecasting functionality.

The forecast can help with:

- Budget planning
- Financial planning
- Future revenue expectations
- Business decision-making

---

### 📑 Income Statement

The Income Statement section provides a detailed view of:

- Revenue
- Cost of Sales
- Operating Expenses
- Operating Profit
- Interest Income
- Interest Expense
- Taxation
- Net Profit

---

### 🏦 Balance Sheet

The Balance Sheet section analyzes:

- Assets
- Liabilities
- Owners' Equity
- Cash & Cash Equivalents
- Inventory
- Investments
- Receivables
- Property, Plant & Equipment
- Payables
- Long-Term Obligations
- Retained Earnings
- Share Capital

The dashboard provides both a summary and detailed view of the Balance Sheet.

---

### 💵 Cash Flow Analysis

The Cash Flow Analysis visualizes different cash flow activities, including:

- Operating Activities
- Investing Activities
- Financing Activities
- Cash & Cash Equivalents

This helps understand the organization's cash movement and financial activities.

---

## 🎛️ Interactive Features

The dashboard includes interactive filters that allow users to analyze the financial data dynamically.

### Available Filters

- **Year**
- **Region**

Users can select different years or regions to analyze financial performance based on their selected criteria.
